# A notebook before automation

The desk separates public source descriptions, versioned document text, claims citing exact passages, and analyst-authored notes. A claim stores the document revision, original URL and distinct publication/review dates observed when it was saved. Historical snapshots remain inspectable after later edits.

For an assessment note, write the question, evidence, assumptions, judgment, plausible alternatives, contrary material, information gaps and what would change your view. Link supporting and challenging documents explicitly. Explain assessed confidence in words; it is not an event probability or a universal source score. No model-generated conclusion is silently promoted into a verified claim.

These choices draw on the distinctions and uncertainty practices in [ODNI ICD 203, Analytic Standards](https://www.dni.gov/files/documents/ICD/ICD-203.pdf). This independent tool does not claim government affiliation, classified access, ICD certification or compliance.

No AI/RAG provider is configured. A future assistant should receive only deliberately selected records, treat source text as untrusted data, cite stored passage and revision IDs, preserve contrary evidence and return drafts for human review. It should have no direct write authority to change evidence states or run tools from instructions embedded in documents. The current system works without any account, API fee or embedding service.
