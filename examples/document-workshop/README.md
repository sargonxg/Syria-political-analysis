# Inspectable local-document examples

`practice.txt` is fictional text for learning the workflow. `annotations.json`
labels its request, attributed report and analyst proposal manually; none is
independently verified. `request-selection.json` is the complete, bounded
`policy-document-workshop/1` packet, with only its first paragraph retained.

`evaluation-fixture.json` supplies five explicit paragraph-ID rubric cases.
`evaluation-results.json` records retained/missing/extra paragraph IDs and real
UTF-8 payload sizes. It intentionally includes both an overbroad selection and a
selection that misses a rubric paragraph. This is a contract/payload exercise,
not an externally reviewed relevance benchmark, substantive accuracy evaluation
or measured AI-quality improvement. No model was called.

Run, validate and adapt these files using the [workshop guide](../../docs/document-workshop.md).
The earlier source-verified Resolution 2254 workflow remains a separate format.
