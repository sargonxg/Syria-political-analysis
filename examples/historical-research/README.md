# Source-qualified historical research examples

These two small selections were produced by the documented `research-query` command from the committed UCDP GED 26.1 and World Bank snapshots. They contain actual source rows and no generated analyst assessment.

| File | Source scope | Selection |
| --- | --- | --- |
| [syria-events.json](syria-events.json) | Syria, 2024–2025, provider state-based category, geographic precision code 1 | First 12 of 323 matching records, sorted by date and ID; explicitly truncated |
| [syria-country-context.json](syria-country-context.json) | Syria, constant 2015 US$ GDP, requested 2011–2025 | All 12 available annual values, 2011–2022; no later values invented |

Run `policy-analysis validate-selection <file>` or open either in the separate [Workbench research-selection reader](https://github.com/sargonxg/tacitus-workbench). Original provider attributes, dataset release identity, licences and scope stay attached. A source row is not independent corroboration or a completed policy judgment.

The question in each file is an original research prompt. Assessment, alternatives and gaps remain blank for the analyst. [Reproduction and practical workflows](../../docs/historical-atlas.md).
