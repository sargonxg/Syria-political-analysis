Use this beyond the browser

The public toolkit builds this self-contained explorer from validated records. It works offline, on a local server or as static Cloudflare assets.

pip install -e '.[dev]'
policy-analysis --country SY context-layers \
  --question "Your research question" \
  --format html --output dist/index.html
python -m http.server 8766 --directory dist
