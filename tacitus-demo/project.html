Local public-source toolkit

Syria-political-analysis

Query historical provider records, inspect source fields and export a bounded research selection without inventing a political conclusion.

Historical datasets, curated source profiles and private notebooks have separate coverage and access requirements. Records are not a current event feed.

Run the actual project

Python 3.11+; committed datasets are separate from live collection.

python -m pip install -e ".[dev,desk,test]"
python -m unittest discover -s tests -v
python scripts/build_showcase.py
python -m http.server 8766 --bind 127.0.0.1 --directory dist

These are application instructions. Check the repository guide for recorded pass/fail results before treating them as verified. The mansion is a separate synthetic teaching demo.
