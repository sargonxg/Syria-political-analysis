# Archival evidence — not static-site assets

These files preserve the official release's codebook, download-center rights
statement, CC BY 4.0 deed/legal text and HTTP/hash receipts from 2026-11-05.
They are untouched originals. Some cover material outside this publication's scope;
the static builder deliberately copies none of this directory.

The full global ZIP remains an external local research archive, pinned by size and
SHA-256 in the snapshot metadata. Only the screened finite selection's JSON parts
are copied to the atlas. Original retained values, provider identity, attribution,
uncertainty and modification notice are preserved.

See [provenance, selection and refresh documentation](../../../../docs/historical-events.md).
